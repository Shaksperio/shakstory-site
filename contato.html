Dúvidas sobre o site, os planos ou a navegação? Veja como encaminhar uma mensagem com segurança.

Dúvidas gerais sobre o site

O repositório do site comercial mantém um espaço público no GitHub para apontar problemas de navegação, comunicar links incorretos ou fazer perguntas gerais relacionadas às páginas.

Abrir uma solicitação pública ↗Ver solicitações existentes ↗

Atenção: o GitHub Issues é público. Não compartilhe nome completo, CPF, comprovantes, e-mail pessoal, senhas, manuscritos, dados de pagamento nem informações confidenciais.

Assinaturas e pagamentos

Os pagamentos são realizados na Ton. Para tratar de uma transação, procure o atendimento oficial disponibilizado no comprovante ou no próprio checkout. Para assuntos de conta e acesso ao editor, utilize apenas canais privados oficialmente apresentados no aplicativo.

Solicitações particulares ou sobre dados pessoais

Não foi informado um e-mail de atendimento privado para publicação neste site. Por esse motivo, ainda não exibimos um endereço de contato não verificado nem disponibilizamos um formulário que recolha dados pessoais sem um canal de atendimento definido.

Quando o Shakstory disponibilizar um contato privado oficial, esta página poderá ser atualizada para incluir esse canal e orientações específicas para solicitações de privacidade.

Conheça o editor

Se sua dúvida for sobre as funcionalidades, você pode consultar a descrição dos planos comerciais ou acessar o editor, conforme suas condições de uso.
